Snake
-----

A classic **snake game** with a modern twist, built with HTML, CSS, and vanilla JavaScript. This project features custom branding, responsive controls for desktop and mobile, and a dynamic game board.

✨ Features
----------

*   **Responsive Design**: Playable on any device, from mobile phones to desktop.
    
*   **Dual Controls**: Use WASD or Arrow Keys on desktop, and Swipe Gestures on touch devices.
    
*   **Dynamic Grid**: The game board expands as your snake grows, increasing the challenge.
    
*   **High Score Tracking**: Your high score is automatically saved in your browser's local storage and cookies.
    
*   **Custom Branding**: Themed around photography with my color scheme and custom icons.
    
*   **Pure JavaScript**: No external frameworks or libraries needed, just clean, modern JS.
    

🎮 How to Play
--------------

### Start the Game:

*   Click the **Start Game** button.
    
*   Press any **Arrow Key** or **W, A, S, D**.
    
*   Swipe on a touch screen.
    

### Objective:

*   Control the snake to eat the emoji food items (📸, 💡, 📱, etc.).
    
*   Each food item you eat makes the snake longer and increases your score.
    
*   Try to beat your high score!
    

### Game Over:

*   The game ends if you run into the walls or into the snake's own body.
